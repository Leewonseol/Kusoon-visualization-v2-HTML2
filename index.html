각 파일은 Plotly가 포함된 self-contained HTML이라 처음 열 때 몇 MB를 내려받습니다.

  • 메인

    전체 시간·정책 대시보드

    1776–1799 공통 시간축 위에 구순의 관직·법정 품계, career_state, 사건·관계, 정조대 정책 milestone을 나란히 표시합니다. 점을 클릭하면 같은 해·전 해·다음 해 정책이 나옵니다(동시성만, 인과 아님).

이 시각화는 입력 CSV에 기록된 관계만 보여줍니다. 연결 수·중심성은 실제 영향력이 아니라 기록 보존량을 반영하며, 정책과 구순 사건이 같은 시기에 보이는 것은 인과관계를 뜻하지 않습니다. 자세한 방법과 검증 결과는 분석 README (Markdown 원문)에 있습니다.
